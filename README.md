<h1>Day 7 ---> Hangman Game</h1>

<p>
A simple Hangman game built using Python and Object-Oriented Programming.
In this project, the player guesses a hidden word one letter at a time before running out of chances.
It is a small game, but a fun way to practice logic, classes, methods, and user interaction.
</p>

<h2>Features</h2>
<ul>
  <li>Random word selection for each game</li>
  <li>Letter-by-letter guessing system</li>
  <li>Tracks correct and wrong guesses</li>
  <li>Limited lives for the player</li>
  <li>Win or lose result at the end</li>
  <li>Clean OOP structure using class and methods</li>
</ul>

<h2>Tech Used</h2>
<p>Python, OOP concepts, basic game logic</p>

<h2>Why I Built This</h2>
<p>
I created this project as part of my Simple OOP Project Series to understand how object-oriented programming can be used in small and interactive projects.
</p>
